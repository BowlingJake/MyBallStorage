# Training Recap Page - Tech Borderless Design v3.0
**Project**: StrikeTrack - Training Recap Tech Redesign  
**Date**: 2025-07-28  
**Goal**: 基於資訊強度的深色科技風邊框式設計

## 📊 設計需求分析

### 資訊強度分級系統

#### 🔥 強 (主要資訊 - 醒目展示)
1. **使用者名稱** - 大字體, 主色調
2. **訓練標題** - 醒目位置, 清晰可讀  
3. **各局分數 & 詳細拋球結果** - 最大空間配置
4. **平均分、全倒率、Spare率** - 統計數據區域

#### 🔶 中 (重要次要 - 依附主資訊)
1. **擲球風格 & 慣用手** - 依附使用者名稱
2. **地點、時間、油圖** - 依附訓練標題

#### 🔸 弱 (輔助資訊 - 空白處補充)
1. **視覺導瓶圖片** - 可選顯示, 極小化處理

### 🎨 深色科技風設計語言

#### 邊框式元件哲學
- **無背景填充**: 完全透明背景，僅用邊框定義區域 
- **發光邊框**: 使用品牌藍綠色 (#4A9EAF) 創造科技感
- **分層邊框**: 主要/次要區域使用不同邊框樣式
- **極簡線條**: 直線為主，圓角適度使用

## 🎨 視覺設計細節

### 邊框效果層級
```dart
// Level 1: 主要容器 (發光邊框)
BoxDecoration(
  border: Border.all(
    color: TechBorderColors.primary,
    width: 2.0,
  ),
  borderRadius: BorderRadius.circular(8),
  boxShadow: [
    BoxShadow(
      color: TechBorderColors.primary.withOpacity(0.3),
      blurRadius: 8,
      spreadRadius: 1,
    ),
  ],
)

// Level 2: 次要區域 (標準邊框)  
BoxDecoration(
  border: Border.all(
    color: TechBorderColors.secondary,
    width: 1.0,
  ),
  borderRadius: BorderRadius.circular(6),
)

// Level 3: 輔助區域 (淡色邊框)
BoxDecoration(
  border: Border.all(
    color: TechBorderColors.tertiary,
    width: 1.0,
  ),
)
```
