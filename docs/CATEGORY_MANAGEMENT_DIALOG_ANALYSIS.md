## 📱 UI 組件詳細分解

### 1. 標題區域 (`_buildHeader`)

**視覺設計：**
- 背景：主色調，透明度 0.1
- 僅頂部圓角 (24px)
- 固定內距：四周 20px

**組件：**
- **左側：** 分類圖標 (Iconsax.category, 24px, 主色調)
- **中央：** 標題文字「管理球袋分類」（繁體中文）
- **右側：** 關閉按鈕 (Iconsax.close_circle)

### 2. 分類列表區域 (`_buildCategoryList`)

**容器：**
- ReorderableListView.builder，16px 內距
- 支援拖拽重排序
- 載入狀態顯示 CircularProgressIndicator

**每個分類項目 (`_buildCategoryItem`)：**

```
┌─────────────────────────────────────────────────────────┐
│  [圖標]  分類名稱                      [編輯] [刪除]    │
│   48x48  描述                          按鈕             │
│          [預設徽章]       [拖拽手柄]                     │
└─────────────────────────────────────────────────────────┘
```

**項目結構：**
- **背景：** 分類主題色，透明度 0.05
- **邊框：** 分類主題色，透明度 0.2，16px 圓角
- **圖標容器：** 48×48px，12px 圓角，主題色背景
- **內容：**
  - 標題：分類名稱（繁體中文）
  - 副標題：描述（如果存在）
  - 預設分類的「預設」徽章（藍色背景）
- **操作：**
  - 編輯按鈕 (Iconsax.edit, 主色調)
  - 刪除按鈕 (Iconsax.trash, 錯誤色，預設分類時隱藏)
  - 拖拽手柄 (Iconsax.menu, 灰色)

### 3. 底部操作區域 (`_buildBottomActions`)

**視覺設計：**
- 背景：表面色，透明度 0.8
- 僅底部圓角 (24px)
- 頂部邊框，輪廓色

**組件：**
- **關閉按鈕：** OutlinedButton 配 Iconsax.close_circle + 「關閉」
- **新增分類按鈕：** ElevatedButton 配 Iconsax.add + 「新增分類」
- 等寬分配，12px 間距

## 🔧 次要對話框：CategoryEditDialog

### 結構
- 標準 AlertDialog 格式
- 標題：「編輯分類」或「新增分類」（繁體中文）
- 可滾動內容區域

### 內容區塊

#### 1. 文字輸入欄位
- **分類名稱：** 必填文字欄位，標籤「分類名稱」
- **描述：** 選填多行文字欄位，標籤「描述 (選填)」

#### 2. 圖示選擇
- **標籤：** 「選擇圖示」（繁體中文）
- **網格布局：** Wrap 小工具，8px 間距
- **可用圖示：** 10 個預定義 Iconsax 圖示
- **選擇樣式：** 
  - 已選：主題色背景 + 邊框
  - 未選：表面背景 + 輪廓邊框
  - 尺寸：48×48px 容器

#### 3. 顏色選擇
- **標籤：** 「選擇顏色」（繁體中文）
- **網格布局：** Wrap 小工具，8px 間距
- **可用顏色：** 10 個預定義顏色
- **選擇樣式：**
  - 圓形容器 (32×32px)
  - 已選：顯示白色勾號 + 深色邊框
  - 未選：純色圓圈

#### 4. 操作按鈕
- **取消：** TextButton 配「取消」
- **儲存：** ElevatedButton 配「更新」或「創建」

## 🎯 互動功能

### 1. 拖拽重排序
- 長按啟動拖拽
- 拖拽過程中的視覺回饋
- 完成重排序後自動同步後端

### 2. 分類管理
- **編輯：** 開啟 CategoryEditDialog，帶入目前值
- **刪除：** 顯示確認對話框（繁體中文）
- **創建：** 開啟空白 CategoryEditDialog

### 3. 預設分類保護
- 預設分類無法刪除
- isDefault === true 時隱藏刪除按鈕
- 特殊「預設」徽章視覺指示器

## 🌐 目前語言與圖示

### 文字語言
- **所有 UI 文字均為繁體中文**
- 範例：「管理球袋分類」、「新增分類」、「編輯分類」、「關閉」、「預設」

### 圖示使用
- **大量依賴 Iconsax 圖示**
- 用於標題、按鈕、分類項目和選擇網格
- 全域一致的 20-24px 尺寸

### 色彩系統
- **主色調** 用於主要元素
- **分類特定顏色** 用於項目背景和邊框
- **語義顏色**（刪除用錯誤紅色，編輯用主色調）

## 📊 視覺層次

### 資訊架構
```
對話框容器
├── 標題 (固定)
│   ├── 圖示 + 標題
│   └── 關閉操作
├── 內容 (可滾動)
│   └── 分類項目
│       ├── 視覺識別 (圖示 + 顏色)
│       ├── 資訊 (名稱 + 描述)
│       ├── 狀態 (預設徽章)
│       └── 操作 (編輯 + 刪除 + 拖拽)
└── 頁尾 (固定)
    ├── 取消操作
    └── 主要操作 (新增)
```

### 設計一致性
- **邊框圓角：** 全域 12-24px
- **間距：** 一致的 8-20px 間隙
- **圖示尺寸：** 操作用 20-24px，顯示用 48px
- **顏色透明度：** 背景 0.1-0.2，表面 0.5-0.8
